# Transferring a complete safe-row family exclusion

GLOBAL STATUS: OPEN. This supplies a necessary component restriction in a
specific actual signed geometry, not a whole-geometry nonexistence theorem.

For a safe core pair C, its outside component has no negative cubic term.
If P is its number of positive unit cubic coefficients and Q its number
of negative unit linear coefficients, evaluation at zero gives P-Q=4.
The complete 4,256-row catalog has P in {6,8,12}, hence Q in {2,4,8}.
The actual-domain audit and the first-row quotient give complete coverage
for this fixed signed geometry and its marked pair.

Suppose the accepted first-row frontier excludes every quotient row with
P=12. Coordinate relabelings preserve the size of the positive family.
Thus no actual Boolean completion in the geometry can have Q=8 on the
marked pair, even for a raw catalog row outside the quotient representatives.
Consequently that component must have Q<=4.

Now let a coordinate permutation preserve the complete signed exceptional
spectrum (the four negative doubles and two positive doubles) and send
the marked pair to another safe pair D. The common four-coordinate core
is preserved because it is the intersection of the positive supports.
The permutation sends each outside linear coefficient of the marked
component bijectively to an outside linear coefficient of the D component,
so Q is preserved. If a completion had Q_D=8, applying the inverse
permutation would produce a completion with Q=8 on the excluded marked
pair. This is impossible. The same Q<=4 restriction therefore holds on D.

The independent checker must verify the exact frontier scope, all quotient
rows of the excluded family, the coefficient-count identity on every safe
catalog row, and each literal coordinate map. It does not need to trust
the automorphism program or assume invariance of the unknown Boolean function.
No claim is made for a safe pair lacking a checked transport.

When extending an already checked partial search, append this necessary
restriction as a new relation. Replacing an old relation in place would
change the meanings of its recorded propagation steps. UNKNOWN remains
inconclusive, and a possible six-component tuple is still not a Boolean
construction.
