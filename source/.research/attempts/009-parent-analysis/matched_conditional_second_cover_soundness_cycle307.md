# Conditional second-row coordinate covers

GLOBAL STATUS: OPEN.

Fix one source row from the accepted first-row quotient in an actual signed
geometry. Its literal embedding fixes every coefficient in that row, including
zeros, as well as the actual negative and positive double supports. Select a
different safe core pair as the marked second pair.

A permutation used by a conditional cover must preserve this entire fixed
spectrum and both marked pairs. It then sends any actual Boolean completion
of the first row to another completion of that same first row and geometry.
For each of the 4,256 possible second rows, an explicit such permutation
must send its full literal spectrum to a listed second-row representative.
Checking these maps proves the conditional cover. No completeness property
of a canonicalizer or invariance of the unknown function is assumed.

The pilot selects one surviving first row per source-row family. It covers
all second rows only conditional on those sampled first rows. It does not
cover unsampled first rows or exclude any geometry. The known first spectrum
and both marked pairs must remain part of every independent map check.

These covers cannot be inserted into an arbitrary existing search node:
additional restrictions accumulated along its path might not be preserved
by the maps. They are applicable at a fresh branch that fixes only the
proved geometry and its first row, or after proving preservation of every
additional restriction.
