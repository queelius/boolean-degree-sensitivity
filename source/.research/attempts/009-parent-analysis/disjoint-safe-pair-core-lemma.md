# Two disjoint safe pairs remove all cubic core characters

Let C be the quartet common to the two positive double quintics and suppose
C=P union Q for two disjoint safe pairs. In the accepted pair catalog, every
coefficient containing P and exactly one of the other core vertices is zero.
This follows directly from its unit faces and linear numerators: the two other
core variables occur only together in the two doubled faces. The same holds
for Q. Every triple of C contains P or Q, so all Fourier polynomials for an
exact three-element intersection with C vanish identically.

There is also a local proof directly from a Boolean core word. Its derivative
on P has values(t,t+delta,t+delta,t) on Q. The two nonconstant linear Walsh
coefficients of this two-variable derivative vanish, killing both cubic core
characters containing P. Interchanging P and Q kills the other two. Its full
quartic core Walsh sum is4delta, where delta=(z_a+z_b)/2 for the two outside
positive apices. Thus for fixed outside bits every core word has all four cubic
Walsh sums zero and full-core sum in{-4,0,4}. Direct finite enumeration yields
526 words. This is a necessary local restriction, not a Boolean function on14
variables or a nonexistence proof.

The first complete screen considers the4256 possible literal companion rows
for each of the three canonical first-row templates. At each outside point,
it compares the two catalog derivative values with the exact relation obtained
from Boolean core words obeying the accepted low/high-layer truth guards.
A saved outside point where the derivative pair is absent is an exact local
contradiction. A row that passes every point remains unresolved because these
separate core words need not fit one common degree-five polynomial.

All literal first-row coordinate maps preserve both marked pairs and positive
supports. Actual signed geometries containing a safe matching are explicitly
mapped to the abstract frame. Their other safe pairs and negative positions
are omitted, which weakens the necessary model. No symmetry of an unknown
function is assumed. A separate scalar replay must verify the proposed screen
before any exclusion is accepted.
