# Actual-geometry first-row transport

GLOBAL STATUS: OPEN.

Fix one of the actual signed geometries with two positive and four
negative double quintics and a safe matching. Its complete component
instance has one domain for each of the six core-pair cubics. Pick a
safe pair C. Its domain consists of the 4,256 checked derivative rows.

For every such row r, the cover gives a coordinate permutation sigma
that fixes C, preserves the sets of positive and negative double
supports, and sends the entire row embedding (including prescribed
zero coefficients) to a selected representative. The independent
reader checks these facts literally for every row. The canonicalizer
is used to discover maps; its group calculation is not a proof input.

If an actual Boolean function exists in this signed geometry, apply
the supplied permutation for its row at C. Coordinate permutation
preserves degree, f(0), full sensitivity there, self-duality in the
proved branch, and the layer guards. It preserves this exact signed
geometry. The transformed function has a representative row at C;
its other five pair components belong to the previously checked
complete component domains. Its pointwise core words satisfy the
same six-component relations. Thus the representative-row instance
still covers every actual function up to explicit coordinate transport.

This does not assert that an arbitrary relaxed component tuple is
preserved by every permutation, nor does it require an invariant
function. It is a case cover for actual functions. The restricted
component domain is not a literal list of all possible first rows;
the manifest therefore records completeness up to transport rather
than marking all component domains literally complete.

For geometry 34, marking the middle safe edge gives 292 representatives.
For geometry 19, marking one safe edge gives 120. These counts remain
subject to the independent map audit until that audit succeeds. No
geometry is excluded by the quotient alone.
